# Безопасность и приватность

## Что хранится локально

LW TrustTunnel Client хранит настройки серверов локально на компьютере пользователя.

В папке `lwtt_app/profiles` могут находиться:

- адреса серверов;
- имена пользователей;
- пароли;
- параметры сертификатов;
- локальные копии `.pem` сертификатов.

## Что не должно попадать в GitHub

В репозитории и публичных архивах не должно быть:

```text
profiles/
profiles/certificates/
profiles/backups/
*.pem
lwtt_client.toml
log/
settings/
LW_TrustTunnel_Client_diagnostic_*.txt
```

## Диагностические файлы

Диагностические файлы помогают разбирать ошибки, но могут содержать техническую информацию о компьютере и сервере. Перед публикацией в открытом доступе их нужно проверять и очищать.

## Права администратора

Права администратора нужны для запуска TrustTunnel и работы сетевого адаптера Wintun. Не запускайте приложение из непроверенных источников.

## Журналы восстановления и настройки обхода

`lwtt_app/log/connection_recovery.json` и `files_recovery.json` могут содержать исходные конфигурации с паролями. Они нужны для восстановления после сбоя и удаляются после успешного завершения операции. Не публикуйте их и не удаляйте до восстановления. Хранение Base64 внутри журнала не является шифрованием.

Личный список обхода находится в `lwtt_app/settings/bypass.json`. Профили и настройки хранятся в доступной пользователю папке установки; приложение не добавляет отдельное шифрование файлов. Для защиты от других пользователей компьютера используйте подходящие права доступа Windows.

Оба сборщика копируют оболочку по явному списку публичных файлов. Папки профилей, журналов и личных настроек в публичные архивы не включаются. Экспорт диагностики скрывает известные логины и пароли, однако технические адреса и сведения о компьютере могут оставаться.
