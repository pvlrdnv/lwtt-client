# Обход VPN

Начиная с версии 4.17 список обхода общий для всех серверов. Адреса из списка открываются напрямую через обычное подключение. Это работает с режимом профиля `vpn_mode = "general"`.

1. Откройте меню значка приложения в трее и выберите **Обход VPN…**.
2. Отметьте **Включить обход VPN для всех серверов** в выделенном верхнем блоке. Жёлтый фон помогает заметить выключенный обход, голубой показывает выбранное включение.
3. Вставьте список, по одному адресу на строку.
4. Нажмите синюю кнопку **Сохранить и применить** справа внизу. Кнопка **Закрыть** находится слева.

Пример:

```text
example.ru
*.example.ru
203.0.113.10
192.168.50.0/24
2001:db8::/32
```

Адреса выше приведены как примеры формата. Для основного домена и всех его поддоменов добавьте обе строки: `example.ru` и `*.example.ru`. Путь отдельной страницы не является правилом обхода. Если вставлены ссылки, кнопка **Извлечь домены из ссылок** преобразует их в домены; перед сохранением проверьте результат.

Пустые строки и строки с `#` пропускаются, повторяющиеся правила удаляются. Ошибка формата показывает номер строки. IP-адреса и подсети могут быть IPv4 или IPv6. Порты в общем списке не задаются.

При включённом VPN приложение переподключается к текущему серверу. При выключенном VPN список применяется при следующем подключении. Если переподключение не удалось, список остаётся сохранённым; результат операции показывается в трее. Для применения можно повторно подключиться к нужному серверу.

Личные настройки находятся в `lwtt_app/settings/bypass.json`. Ручные `exclusions` в файлах серверов сохраняются и объединяются с общим списком только в активной конфигурации. Выключение общего обхода отключает лишь общий список; правила самого профиля продолжают действовать. Системные исключения локальных сетей в `excluded_routes` не меняются.

После изменения правил откройте новое соединение с сайтом; браузер может продолжать использовать уже открытое. Работа доменных исключений также зависит от DNS и протокола. Для сборки с TrustTunnel v1.0.49 проверка реального обхода в вашем браузере с защищённым DNS выполняется отдельно.
