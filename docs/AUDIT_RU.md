# Проверка проекта LW TrustTunnel Client

Проверка исходников, интерфейсных текстов, инструкций и сборки выполнена 24 ноября 2026 года. Исправления включены в версию 4.19. Версия движка TrustTunnel осталась закреплённой на v1.0.49.

## Найденные и исправленные ошибки

| Область | Ошибка | Исправление |
| --- | --- | --- |
| Диагностика | Сортировка с Unique по длине могла оставлять в экспорте другие пароли той же длины | Уникальность определяется по значению, затем секреты упорядочиваются по длине |
| Восстановление | Исключение чтения журнала могло прервать откат подключения | Диагностика изолирована от обязательного восстановления |
| Проверка сервера | Неудача восстановления вызывала повторный запуск восстановления и могла выглядеть как ошибка проверяемого сервера | Отдельная фаза и сообщение Restoration; журнал сохраняется для явной повторной попытки |
| Статус туннеля | Старый журнал мог быть принят за состояние другого процесса | PID из метаданных сессии сверяется с текущим процессом |
| Фоновые задания | Повторно использованный PID мог оставлять завершённое задание в состоянии ожидания | Получение результата проверяет имя процесса и время его старта |
| Запись файлов | Ошибка удаления промежуточного backup могла сообщить о неудачной записи после фактической замены файла | Атомарная замена выполняется без лишнего backup; журнал транзакции остаётся механизмом отката |
| Поля редактора | Ошибка домена немедленно стиралась очисткой прежних ошибок | Очистка выполняется до проверки; ошибка остаётся у поля |
| Профили | Зарезервированные Windows имена разрешались до ошибки записи; активный идентификатор не проверялся | Ограничены имена устройств и длина; путь активного профиля проверяется; повреждённый указатель или профиль не прерывает запуск интерфейса |
| Удаление | Повреждённый профиль не удалялся; активность не перепроверялась после подтверждения | Неактивный повреждённый профиль можно удалить; после подтверждения активность проверяется под блокировкой |
| Сохранение | Перезапись другого профиля с именем активного не всегда учитывала необходимость применения | Активность определяется также по новому имени профиля |
| Расположение элементов | Изменение области просмотра во время пересчёта могло остаться без повторного пересчёта | Запрашивается один дополнительный проход после завершения текущего |
| Сертификаты | SAN разбирался через зависящий от языка Windows текст; CN смешивался с SAN | Имена SAN читаются из DER; CN используется при отсутствии SAN |
| Сертификаты CA | Имя удостоверяющего центра ошибочно сравнивалось с доменом сервера | CA определяется через Basic Constraints; проверку цепочки и домена при подключении выполняет движок |
| TOML | Стандартная многострочная строка с двойными кавычками не читалась как PEM | Поддержаны оба типа многострочных строк и корректные продолжения строк |
| Параметры | Неверный числовой IPv4 мог приниматься за домен; произвольный текст с цифрой 2 или 3 за протокол | Добавлены проверки IPv4 и допустимых обозначений протокола |
| Обход VPN | Строка JSON "false" превращалась в логическое true | Enabled должен содержать логическое значение без кавычек |
| Запуск Windows | Проверка администратора зависела от службы Server; код ошибки дочернего запуска мог теряться | Проверяется Windows principal, коды завершения сохраняются |
| Поиск менеджера | Скобки в пути интерпретировались как маска поиска | Путь сопоставляется как обычная строка |
| Проверка архивов | Python -O отключал assert в инструменте проверки | Используются явные исключения; добавлены проверки путей и актуальности текстов |
| Служебные скрипты | Старый преобразователь структуры мог менять текущую версию проекта | Преобразователь разрешён только для исходной версии 4.15 |
| Инструкции | Неточное название сертификата сервера, старая плоская структура, неверные пути автозапуска, повреждённые пути с табуляцией и backspace, обещание скачивания последнего движка | Пути, структура, описание закреплённой версии и тексты приведены в соответствие с приложением |

## Проверки

Для исправлений добавлены проверки в `tests/audit.ps1`, `tests/interface.ps1` и `tests/static.py`. Основной набор `tests/run.ps1` дополнен проверкой соответствия журнала PID процесса. Проверки используют временные папки и подмену реальных операций VPN.

Проверяются синтаксис PowerShell, Python и Bash; восстановление при искусственных сбоях; скрытие секретов; атомарная запись; формы и сертификаты SAN/CA; правильность ссылок и публичных текстов; оба сборщика; состав и контрольные суммы итоговых архивов.

## Практические ограничения

Автоматические проверки не подключаются к настоящему VPN, не устанавливают сертификаты в доверенное хранилище Windows и не меняют системные маршруты. Работу Wintun, UAC, реального DNS и HTTP/3, автозапуск и видимый интерфейс при разных DPI нужно проверять на рабочей Windows-машине. Полный перечень: [результаты проверок](VERIFICATION_RU.md).

Разбор TOML в редакторе предназначен для используемых приложением полей. Это не универсальный TOML-редактор: нетипичные формы управляемых полей, которые он не поддерживает, могут потребовать ручной правки. Неизвестные дополнительные параметры сохраняются.

Журналы текущей сессии TrustTunnel могут расти во время долгой работы; число сохранённых сессий ограничено при следующем запуске. Локальные профили и журналы восстановления содержат настройки в открытом виде, поэтому их нельзя публиковать.

## Технические источники

- [RFC 5280, Subject Alternative Name](https://www.rfc-editor.org/rfc/rfc5280#section-4.2.1.6): формат расширения SAN.
- [NullString.Value в PowerShell](https://learn.microsoft.com/en-us/dotnet/api/system.management.automation.language.nullstring.value): передача null вместо пустой строки в вызовах .NET.
