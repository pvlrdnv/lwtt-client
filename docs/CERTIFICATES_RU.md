# Сертификат сервера

Начиная с версии 4.18 PEM-файл необязателен. По умолчанию приложение проверяет сертификат сервера через системное хранилище доверенных сертификатов Windows. Проверка подлинности сервера остаётся включённой.

## Подключение без файла

Добавьте настройки сервера и нажмите **Сохранить и подключить**. Раздел **Сертификат сервера · необязательно** по умолчанию свёрнут. Упоминание PEM или самоподписанного сертификата в сообщении бота не блокирует сохранение и проверку подключения.

Если сервер использует сертификат от доверенного Windows центра, домен совпадает и цепочка настроена правильно, отдельный файл не требуется. Само наличие сертификата на сервере ещё не означает, что Windows ему доверяет.

## Добавление и замена PEM

1. Разверните раздел **Сертификат сервера**.
2. Нажмите **Добавить PEM** и выберите сертификат от администратора сервера.
3. Сохраните профиль или выберите **Сохранить и подключить**.

Выбранный PEM встраивается в конфигурацию и используется при проверке подключения. Раздел доступен также при редактировании существующего сервера; в свёрнутом виде он показывает **PEM добавлен**. Кнопка **Заменить** позволяет выбрать новый файл. Если новый файл не удалось прочитать, прежний сертификат остаётся выбранным.

Существующие сертификаты профилей сохраняются при обновлении приложения. Автоматически удалять их или переключать такой профиль на системное доверие приложение не будет.

## Удаление PEM

В редакторе разверните раздел сертификата и нажмите **Удалить**, затем сохраните профиль. Сертификат удаляется из TOML и локальной копии `lwtt_app/profiles/certificates/<id>.pem`. Исходный файл, который вы выбирали на компьютере, не удаляется. До сохранения профиль на диске не меняется.

После удаления приложение использует доверие Windows. При работающем VPN изменения применяются после переподключения. Если Windows не доверяет сертификату сервера, подключение потребует корректного PEM либо исправления доверия и сертификата на сервере.

## Сообщения об ошибках

При подтверждённой журналом ошибке доверия и отсутствии PEM приложение сообщает, что не удалось подтвердить сертификат сервера, и предлагает добавить файл, если сервер использует самоподписанный сертификат. В менеджере появляется кнопка **Добавить сертификат**, а при проверке сервера раскрывается соответствующий раздел. После подключения из трея там появляется пункт **Добавить сертификат для сервера…**.

Если движок прямо сообщает об истёкшем сроке, ещё не начавшемся сроке или несовпадении домена, показывается отдельное сообщение. Некоторые Windows-коды объединяют несколько причин ошибки доверия, поэтому приложение не утверждает, что отсутствие файла является единственной причиной.

Тайм-аут, ошибка DNS и неверные учётные данные не выдаются за отсутствие сертификата. Диагностика относится к неудачной попытке подключения, даже если приложение затем восстановило предыдущую сессию.

Описание поведения движка: [TrustTunnel v1.0.49, настройки endpoint](https://github.com/TrustTunnel/TrustTunnelClient/blob/v1.0.49/trusttunnel/README.md#endpoint-settings-endpoint).

PEM может содержать сертификат сервера либо доверенного удостоверяющего центра. Для сертификата центра не проверяется совпадение его собственного имени с доменом сервера; проверку цепочки и имени сервера при подключении выполняет движок TrustTunnel. Имена SAN читаются независимо от языка Windows.
