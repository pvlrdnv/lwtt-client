# Диагностика и частые проблемы

## Приложение не запускается

Распакуйте архив целиком. Структура папки:

```text
C:\Trusttunnel\lwtt_tray_start.bat
C:\Trusttunnel\ИНСТРУКЦИЯ БЫСТРОГО СТАРТА.txt
C:\Trusttunnel\lwtt_app\trusttunnel_client.exe
C:\Trusttunnel\lwtt_app\wintun.dll
C:\Trusttunnel\lwtt_app\lwtt_tray.ps1
C:\Trusttunnel\lwtt_app\lwtt_common.ps1
C:\Trusttunnel\lwtt_app\...
```

Сохраняйте все остальные модули приложения. Запустите `lwtt_tray_start.bat` двойным кликом и подтвердите запрос администратора. При отмене UAC приложение не запускается.

## Соединение не устанавливается

Проверьте выбранный сервер, адрес, домен, имя пользователя и пароль. Убедитесь, что архитектура движка подходит Windows и запуск не блокируется антивирусом. Для технического запуска можно открыть `lwtt_app/lwtt_start.bat`: ошибка подключения выводится в консоль.

PEM по умолчанию не требуется. Если журнал сообщает об ошибке доверия, для самоподписанного сертификата может понадобиться файл от администратора. Истёкший срок, неверный домен и неправильная цепочка сертификатов требуют отдельного исправления. Подробнее: [сертификаты](CERTIFICATES_RU.md).

При незавершённой операции используйте **Восстановить подключение** в трее. Не удаляйте журналы восстановления до её завершения.

## Проверка прохождения трафика

Проверьте внешний IP на ресурсе, который не включён в обход VPN. Обычно будет виден внешний адрес VPN-сервера. Один результат сервиса проверки IP не подтверждает доступность всех сайтов. После изменения исключений закройте прежние соединения браузера и откройте новое.

## Ошибки Wintun

Windows может задерживать создание и освобождение сетевого адаптера. Отключите соединение, завершите операции приложения и закройте его через трей. Если это не помогло, перезагрузите Windows и запустите клиент снова.

## Отправка отчёта администратору

В трее выберите **Сохранить журнал диагностики…**. Экспорт скрывает известные логины и пароли, но может содержать технические адреса и сведения о компьютере. Передавайте файл администратору и не публикуйте его открыто. Сырые журналы и файлы восстановления из `lwtt_app/log` не являются очищенным экспортом.
